# Brasero Café (site concept)

Projet personnel de design et d'intégration. Le café est **fictif** : aucune adresse, aucun prix réel et aucune réservation réelle.

## Contenu
- Accueil, carte (cafés et pâtisseries), histoire, formulaire de réservation (démonstration).
- Trois fichiers : `index.html`, `styles.css`, `script.js`. Aucun outil à installer.

## Technique
- HTML sémantique, CSS sans framework, responsive (mobile dès 640 px).
- JavaScript d'une dizaine de lignes pour le formulaire.

## Voir le site
Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur ce dépôt.

## Style et photos
- Police Poppins, palette indigo, lavande et ambre, angles droits.
- Photographies libres de droits issues d'Unsplash (licence Unsplash), utilisées en illustration.
